Quiz Management System

A no-backend, GitHub Pages–hosted quiz platform. Pick your role below to get started.

🧑‍🎓

I'm a Student

Enter your name and roll number to start the assigned quiz. Your progress is saved automatically if you need to pause.
🧑‍🏫

I'm the Instructor

Filter the question bank by unit/topic/difficulty/Bloom level/type, configure a quiz, and generate a shareable student link.

How This Works

This entire application runs in your browser — there is no server and no database. Question banks live as JSON files in this repository (data/*.json), and quiz configuration is either a committed config file or encoded directly into the shareable link the instructor sends out.

See docs/README.md in this repository for full architecture, deployment instructions, JSON schemas, and how to add new units/questions in future semesters.
