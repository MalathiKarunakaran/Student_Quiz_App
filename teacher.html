How This Works

This entire application runs in your browser — there is no server and no database. Question banks live as JSON files in this repository (data/*.json), and quiz configuration is either a committed config file or encoded directly into the shareable link you send students.

See docs/README.md in this repository for full architecture, deployment instructions, JSON schemas, and how to add new units/questions in future semesters.

Two ways to deliver a quiz: (1) generate a shareable link — the entire config is embedded in the URL, so you can send it out immediately with zero repo changes; or (2) download the config JSON and commit it to data/, then share a link like student.html?configFile=data/your-config.json. See docs/README.md for details.
